# 高校评估工作台前端

Vue 3 + TypeScript + Element Plus。控件和图标统一使用 Element Plus，报告正文使用 Marked、DOMPurify 与按需加载的 Mermaid。

## 启动

使用 Node.js 20.19+ 或 22.12+；推荐使用当前支持的 LTS 版本。Node.js 22.2.0 不满足现有 Vite 8 的要求。

在 frontend 目录执行：

```powershell
npm install
npm run dev
```

前端默认端口 5173，`/api` 与 `/static` 请求转发至 `http://127.0.0.1:8008`。后端需另行启动。

```powershell
# 在项目 backend 目录中，使用已安装后端依赖的 Python
python -m uvicorn app.main:app --host 127.0.0.1 --port 8008
```

## 页面

首次打开网页先注册账号；以后使用用户名和密码登录。用户名为3至32位字母、数字或下划线，注册密码为12至128个字符。注册成功会直接进入个人工作空间。右上角账号菜单可退出登录，登录状态最多保留7天。

每个账号独立保存 Excel、数据库、报告、图表和模型配置。旧版未登录时期的数据保留在原目录，不会自动分配给任何新账号。账号存于 `backend/data/accounts.db`，个人数据存于 `backend/data/users/<账号ID>/`。详细说明见 [账号与个人空间](../docs/authentication.md)。

- 工作台：数据准备情况、当前报告与操作指引。
- 数据管理：拖拽或批量选择 Excel；目录默认追加导入。已入库目录每行可删除单个工作表，顶部可“清空全部”，均有确认提示。报告生成期间不能增删数据。删除同步移除当前账号的目录表和来源单元格；上传副本在其全部工作表删除后清理，外部导入目录和示例目录中的原文件保留。载入示例和选择替换导入会清空已有数据，界面会确认。
- 报告生成：确认学校，启动一次 SSE 生成任务。修订阶段替换旧稿；完成后重新读取后端最终正文。
- 报告阅读：章节目录、引用来源浮层和抽屉、Word/Excel 下载。内部 cell 标识不出现在正文中。
- 服务设置：配置当前账号的模型、地址、密钥和执行引擎，重启后保留。密钥加密保存在后端，不写入浏览器存储、不回显；密钥输入框留空表示保留，勾选“停用并清除”可改用本地规则。

刷新页面使用 `/api/pipeline/status` 恢复当前账号最近一次报告。后端把已完成小节、核验结果及导出位置写入该账号的断点文件，重启后仍可查看。中断任务标为未完成，可重新生成，不会自动续跑。

系统保留报告生成过程中的自动核验，不设置人工复核步骤。自动核验结果可在章节详情查看；异常显示为“核验异常”，不会标记为通过。

调整入库数据后，已有报告与导出文件保留，并显示“入库数据已变化，请重新生成报告”；旧报告的核验结果不会自动更新，已删除单元格的来源详情将不可查询。重新生成后，报告使用调整后的数据。清空数据不会删除账号或模型配置。

## 开发检查

```powershell
npm run typecheck
npm run build
npm run format
```

源文件按 `views`（页面）、`components`（报告与抽屉）、`composables/useWorkspace.ts`（接口及任务状态）、`utils/report.ts`（引用与正文格式化）组织。
