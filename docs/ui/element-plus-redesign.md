# Element Plus 前端改造

基于已选择的 Element Plus 方案，将原三栏工作台改为左侧导航与独立业务页面。主题采用深蓝、白色和浅灰；交互控件统一使用 Element Plus 和其图标库，报告正文保留 Markdown、Mermaid 和图片渲染。

## 页面与数据

- 工作台：数据规模、当前任务、操作入口与最近章节。
- 数据管理：拖拽/批量上传、目录导入、示例数据、搜索分页和工作表字段抽屉。
- 报告生成：学校名称、五阶段进度、章节任务和执行日志。
- 质量核验：实际引用匹配、模型评审结果及章节详情抽屉；没有引用记录时显示未核验。
- 报告阅读：章节导航、安全 Markdown 渲染、来源查询、Word 和 Excel 下载。
- 服务设置：模型、地址、密钥、引擎配置；说明配置目前仅保存在后端进程中。

沿用现有 API；状态恢复仅调用 GET /api/pipeline/status，不以 SSE 重连触发新任务。首次加载和请求失败显示明确状态。目录导入默认追加，替换数据与载入示例需提示确认。

## 实施与验证

1. 接入 element-plus、@element-plus/icons-vue 与 vue-tsc，使用中文 locale。
2. 将类型、API/任务状态与 Markdown 格式化从 App.vue 中提取。
3. 实现六个页面及章节、工作表、数据来源抽屉，使用真实后端字段。
4. 验证 Vue 模板类型、生产构建、空态/错误态、典型数据、SSE 事件及常见屏幕宽度。

本次只修改本地前端与说明文件，保留已有后端修复。以浏览器中的实际组件页面作为交付，效果图中的示例数据不写入正式界面。
